# Viewoupe

Viewoupe is a dependency-free in-place reading layer for ordinary web pages. It lets a reader enlarge, isolate, copy, and collect the text they are reading without zooming the whole interface or leaving the current page.

The compact page trigger is `VL`. The stylized brand mark may be written as `view|oupe`; the official project name is **Viewoupe**.

## Why

Browser zoom changes the whole page. Reader modes move content into a separate environment. Viewoupe is built around a smaller interaction unit: the current paragraph, selection, code block, or article.

## Core features

- Local font enlargement with real text reflow, not `transform: scale()`.
- Passive `VL` trigger: no large overlay appears just because the pointer crossed text.
- `Focus` cycle: Focus → Deep → Anchors, with auto-dim on open.
- Three reader-selected anchors that reduce a passage to its semantic skeleton.
- Selection support for working with only part of a paragraph.
- Explicit `Article` mode for a larger reading context.
- `Copy` for the current reading object.
- Temporary `Shelf` for collecting several snippets before transferring them elsewhere.
- Shadow DOM isolation so host-page CSS does not restyle the Viewoupe UI.
- No framework, no account, no AI dependency, and no network requests by default.

## Quick start

Build the distributable file:

```bash
npm run build
```
Then embed it on a page:

```html
<script src="/path/to/viewoupe.js" data-viewoupe></script>
```

For manual initialization:

```html
<script src="/path/to/viewoupe.js"></script>
<script>
  Viewoupe.init({
    selector: 'article p, article li, article pre',
    zoomLevels: [1, 1.2, 1.4, 1.7, 2]
  });
</script>
```

The global API is `window.Viewoupe`.

## Interaction

- Hover a readable block → a small `VL` trigger appears.
- Click `VL` → open and lock the reading layer.
- `Alt+L` → toggle the hovered block or current selection.
- `A−` / `A+` → change local reading size.
- `Focus` → cycle Focus → Deep → Anchors → Focus; Anchors is skipped until at least one anchor exists.
- Select up to 5 words in the reading layer → save them into one of three anchor slots.
- Hover an anchor slot → emphasize its phrase; click a slot → locate it in the text.
- In Anchors mode, click an anchor phrase → temporarily reveal its surrounding text block.
- `Article` → explicitly open the nearest article/main container.
- `Copy` → copy the current block, selection, or article.
- `+ Shelf` → save the current text clip in temporary in-memory Shelf.
- `Shelf (N)` → inspect, remove, copy all, or clear saved clips.
- `Esc` → close Viewoupe and return to the original page.

Shelf data is session-only and disappears on page reload. It is intentionally separate from the system clipboard.

Anchors survive close/reopen for the same reading target during the current page session, but are not persisted across reloads.
## Design principles

Viewoupe does not rewrite the source document. It clones only the chosen reading target into a Shadow DOM overlay, strips active or page-specific attributes, and preserves useful text semantics such as links and code.

The source page remains where it was. Closing Viewoupe returns the reader to the same page context.

## Privacy

Viewoupe 0.2.0 does not send text to a server, does not require sign-in, does not use analytics, and does not persist Shelf contents. A future integration that adds remote services should make that behavior explicit and opt-in.

## Project structure

- `src/viewoupe.js` — source.
- `dist/viewoupe.js` — distributable browser file generated by `npm run build`.
- `examples/` — normal and hostile-CSS test pages.
- `assets/brand/` — official wordmark, icon, favicon, social card, and design tokens.
- `docs/` — architecture, brand, Russian overview, publishing copy, and release notes.

## Local development

```bash
npm run build
npm run check
npm run serve
```

Open `http://127.0.0.1:8765/` for the main example and `/examples/hostile-css.html` for CSS-isolation testing.

## Scope

Viewoupe is a reading-ergonomics tool. It may be useful to people who benefit from larger or more isolated text, but the project does not claim complete accessibility conformance or replace browser/OS accessibility features.
