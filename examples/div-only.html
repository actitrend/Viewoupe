A div-only reading layout

This is a deliberate regression test for pages built from generic div containers. The reading tool should still be able to identify the surrounding story as a coherent reading context.

The fallback is conservative. It looks up from the paragraph for a sufficiently large container with multiple readable blocks, enough text, a sensible visual size, and a link ratio that does not resemble navigation.

If a suitable reading container is found, the Article action stays visible and opens it. If not, the Article action disappears instead of accepting a click that leads nowhere.

This matters because a large part of the web still uses non-semantic markup. A useful reading layer cannot assume that every publisher has perfect HTML semantics.
