«Чужой» сайт с конфликтующим CSS

Эта страница специально оформлена агрессивно. Её CSS принудительно делает все обычные кнопки огромными и красными, меняет шрифты, фон и оформление ссылок. Интерфейс Viewoupe при этом должен остаться своим благодаря Shadow DOM.

Наведи курсор сюда: должен появиться только маленький VL. Нажми VL или Alt+L, увеличь текст и проверь, что панель управления не наследует красные кнопки этой страницы.

Код на чужом сайте

function calculateReadingWidth(fontSize, viewportWidth) {
  const idealCharacters = 68;
  return Math.min(viewportWidth - 48, fontSize * idealCharacters * 0.55);
}

Здесь есть жирный текст, курсив, inline code и ссылка. В Viewoupe семантика должна сохраниться, но агрессивные стили страницы — нет.

Проверка Article mode

После открытия любого этого абзаца нажми кнопку Article. Viewoupe должен осознанно показать содержимое элемента main целиком, а не делать это из-за случайного клика по пустому месту.

Этот режим появился из полезного побочного эффекта первой версии: иногда крупное представление всей статьи действительно удобнее локальной линзы, но теперь оно включается явно.
