Viewoupe: тест локального чтения

Наведи курсор на абзац: появится только маленький маркер VL. Клик по VL открывает линзу. Alt+L открывает текущий абзац с клавиатуры, Esc всегда возвращает обычную страницу.

Проверь: VL по наведению, Alt+L, A− / A+, Focus, Article, Copy и выделение части текста — после выделения VL должен появиться рядом с ним.

Article-style demos

Для длинного непрерывного чтения открой один из трёх сценариев:

  • Long-form essay — почти сплошной текст и длинные абзацы.
  • Technical article — проза, код и таблица.
  • Research note — плотный текст, цитата, список и заметки.

Почему локальная линза может быть удобнее общего масштаба

Глобальное увеличение страницы помогает, когда весь интерфейс слишком мелкий, но оно одновременно увеличивает меню, изображения, боковые панели и другие элементы. Viewoupe решает более узкую задачу: временно сделать удобным именно тот фрагмент текста, который пользователь читает сейчас, не перестраивая всю страницу.

В длинных статьях внимание постоянно перемещается между абзацами. Если один фрагмент особенно сложный или плохо различимый, пользователь может открыть его крупно, изменить размер текста и затем одним нажатием клавиши Escape вернуться в исходный контекст.

Текст со встроенной разметкой

Этот абзац содержит жирное выделение, курсив, фрагмент inline code и обычную ссылку. В линзе базовая смысловая разметка должна сохраниться, но стили исходного сайта не должны проникать внутрь интерфейса Viewoupe.

Проверка длинного абзаца

Хороший режим чтения должен не просто геометрически растягивать исходный текст, а выполнять настоящий reflow. При увеличении размера шрифта строка должна становиться короче, текст — переноситься естественно, а межстрочный интервал — оставаться комфортным. Именно поэтому прототип меняет типографику внутри отдельного изолированного слоя вместо применения CSS transform к исходному элементу страницы.

Цель прототипа — проверить сам паттерн взаимодействия: абзац становится временным интерфейсным объектом, с которым можно работать прямо во время чтения.

Ещё несколько абзацев для прокрутки

Viewoupe не должен заставлять пользователя переходить в отдельный Reader Mode. Контекст страницы сохраняется, а линза появляется только тогда, когда она нужна. После закрытия пользователь остаётся на той же позиции страницы.

В следующей версии можно добавить регулировку ширины строки, межстрочного интервала, контрастности, временную подсветку выбранных слов и режим быстрого просмотра по удержанию клавиши.

Код: JavaScript

Проверь наведение и увеличение на блоке кода. Панель Viewoupe должна оставаться на месте, а длинные строки — читаться внутри линзы.

function findReadableBlock(node) {
  const candidate = node.closest('p, li, blockquote, pre');
  if (!candidate) return null;
  const text = candidate.textContent.trim();
  return text.length >= 24 ? candidate : null;
}
