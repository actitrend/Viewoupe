In-place reading tools for the web

Viewoupe enlarges, focuses, copies, and collects the text you are reading without zooming the whole interface or leaving the page.

Same page. Closer reading.

Viewoupe treats the current paragraph, selection, code block, or article as the unit of interaction. The source page stays untouched.

Local enlargement

Real font-size changes and reflow instead of scaling the whole page.

Focus modes

Normal, dim, and isolate modes reduce surrounding visual noise.

Temporary Shelf

Collect several snippets and copy them together when you are ready.

Reading

Browser zoom is useful when an entire interface is too small. Viewoupe is for the other case: when you want to make only the text you are reading easier to see.

Selection

Select just this sentence, then use VL. Viewoupe will open the selected fragment rather than the complete paragraph.

Code

Viewoupe also works with preformatted content, documentation, tables, headings, and other readable blocks.
