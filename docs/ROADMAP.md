# Roadmap

Viewoupe 0.1.0 is intentionally a frozen baseline for testing the interaction pattern before adding more surface area.

## 0.1.x — validate the core

- Test on 20–30 unrelated real websites.
- Fix target-selection, scrolling, selection, and CSS-isolation edge cases.
- Check keyboard conflicts across major Chromium browsers.
- Improve touch/mobile behavior only if real use cases justify it.
- Record a short public demo and gather user feedback.

## 0.2 — packaging

- Browser-extension shell around the same core.
- Site include/exclude controls.
- Minimal settings for trigger behavior and default zoom.
- Extension privacy documentation and permission review.

## Later, only after validation

- Optional persistent Shelf or export workflows.
- Optional typography controls such as line width or spacing.
- Firefox/Safari packaging if demand exists.
- Remote or AI features only as explicit opt-in modules, not as a core dependency.

## Not planned as core behavior

- Full-page WYSIWYG editing.
- Automatic rewriting of source pages.
- Silent cloud synchronization.
- Continuous animated UI competing with the page content.
