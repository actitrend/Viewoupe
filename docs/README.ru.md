# Viewoupe — кратко по-русски

**Zoom the text, not the page.** — увеличивай текст, а не всю страницу.

Viewoupe — небольшой слой локального чтения поверх обычных веб-страниц. Он позволяет увеличить именно текущий абзац, выделение, код или статью, не меняя масштаб всего сайта и не переходя в отдельный Reader Mode.

## Что умеет 0.1.0

- показывает компактный триггер `VL` рядом с читаемым блоком;
- увеличивает текст с настоящим reflow;
- умеет затемнять или почти полностью изолировать фон через `Focus`;
- работает с выделенным фрагментом;
- явно открывает `Article` mode;
- копирует текущий фрагмент;
- складывает несколько фрагментов во временный `Shelf`;
- изолирует интерфейс от CSS сайта через Shadow DOM;
- не требует аккаунта, AI, облака или зависимостей.

## Зачем

Обычный browser zoom полезен, когда мелкий весь интерфейс. Но иногда нужно сделать удобнее только тот текст, который читается сейчас. Viewoupe решает именно эту локальную задачу.

## Приватность

Версия 0.1.0 не отправляет текст на сервер, не использует аналитику и не сохраняет Shelf после перезагрузки страницы.

## Бренд

Официальное имя: **Viewoupe**. В логотипе допустимо стилизованное `view|oupe`. Компактный маркер внутри страницы: `VL`.
