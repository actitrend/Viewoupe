## Extended product description

Viewoupe adds a small, user-controlled reading layer to ordinary web pages. Hover a readable paragraph, selection, code block, or heading to reveal the compact `VL` trigger. Open it to enlarge that text with real reflow, reduce surrounding distraction with Focus modes, copy the current reading object, or collect several useful snippets in a temporary Shelf.

Unlike full-page zoom, Viewoupe changes only the reading object you choose. Unlike a separate Reader Mode, it keeps you on the original page and returns you to the same context when closed.

Viewoupe 0.1.0 is deliberately small: no account, no AI service, no analytics, no persistent Shelf storage, and no framework dependency.

## Feature bullets

- Local text enlargement with real reflow
- Normal / dim / isolate Focus modes
- Paragraph, selection, code, and Article modes
- Temporary snippet Shelf
- Shadow DOM isolation from page CSS
- Keyboard toggle and reliable Esc close
- No account or remote processing in the baseline version
## Privacy statement

Viewoupe 0.1.0 processes reading targets locally in the page. It does not transmit page text, does not require sign-in, does not include analytics, and keeps Shelf items only in memory until the page is reloaded.

## Developer-story opening

I wanted to enlarge one paragraph in a browser without zooming the navigation, images, sidebars, and everything else. That small problem turned into Viewoupe: an in-place reading layer where the paragraph or selection becomes the unit of interaction.

The early prototype taught an important lesson: even a useful reading tool becomes annoying if it opens automatically. The current version therefore stays passive until the reader explicitly activates the small `VL` control.

## Suggested launch demo sequence

1. Open an ordinary article.
2. Hover a paragraph and reveal `VL`.
3. Open it and press A+.
4. Cycle Focus once.
5. Close with Esc.
6. Select a sentence and reopen Viewoupe.
7. Add three fragments to Shelf.
8. Copy all and show the resulting collected context.
